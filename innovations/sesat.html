SESAT Library System

Advanced library management system. Smart MARC 21 Editor: cataloguing has never been easier.

One System, Every Library

SESAT is a web-based integrated library system (ILS), ready to run in the cloud. One shared database serves many libraries, and staff and readers need nothing more than a web browser.

Built for schools, school networks, universities and institutional libraries.

Key Features

Smart MARC 21 Editor

  • Fully web-based, for expert and new cataloguers alike
  • All MARC 21 tags, sub-fields and indicators, with a built-in validator
  • Automatic authority record linking

Search & Import

  • Find records on Z39.50 and SRU/SRW servers
  • Library of Congress and OCLC integration
  • Import .mrc, .mrk and MARCXML files

Many Libraries, One System

  • Add libraries anytime, each with its own lending rules and fines
  • Shared union catalogue
  • Sign-in through Active Directory and other LDAP servers

Library Operations

  • Check-in, check-out, reservations, holds and fines
  • Serials management and acquisitions
  • Built-in search index for fast results

A Catalogue Readers Love

The online public catalogue (OPAC) helps readers find, save and share resources from any device, in their own language.

  • Faceted search by format, call number, language, author, genre, era and region
  • Suggested resources and searches, plus browsing
  • Favourites lists, tags, comments, and sharing by email or text
  • APA and MLA citations, author biographies and persistent URLs
  • Multilingual interface
